# Ansir Skills

这是我的 Skill 目录导航页。

这个总项目只负责聚合和索引各个真实 Skill 仓库，不重复存放 Skill 源文件。真实 Skill 会在各自独立仓库中维护。

## Skill 目录

| Skill | 简介 | 仓库 |
| --- | --- | --- |
| chinglish | 把中文翻译成搞笑好玩的 Chinglish 英文，保留中文语序和逐字翻译的离谱感。 | https://github.com/AnsirStudio/chinglish |
| second-me-wiki-distiller | 构建和维护由 LLM 维护的个人 Markdown 知识库与 second me 种子。 | https://github.com/AnsirStudio/second-me-wiki-distiller |

## 收录规则

- 每个真实 Skill 使用独立仓库维护。
- 本仓库只上传导航 README。
- 真实 Skill 文件夹只在本地作为工作区存在，不在本仓库重复提交。
- 新增 Skill 时，只在这里增加目录项，不复制真实 Skill 文件夹。
